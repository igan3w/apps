오라테크 · 서뉴으뉴 모바일 앱 센터

7개 웹앱 전체가 홈 화면 앱 설치(PWA)로 동작하도록 제작되었습니다.
각 앱을 열면 스마트폰 앱처럼 상단 주소창 없는 전체화면 + 전용 아이콘으로 홈 화면에 설치할 수 있습니다.

💡 카톡/문자 링크로 열었을 때 주의: 카카오톡 내부 브라우저에서는 "홈 화면에 추가" 버튼이 숨겨져 있습니다.
우측 하단/상단 [⋮ 또는 ⋯] → [다른 브라우저로 열기 (Chrome / Safari)]를 누른 뒤 설치하세요!

🤖 갤럭시 · 안드로이드 (Chrome / 삼성인터넷)

  1. 아래에서 원하는 앱의 [열기 · 설치하기] 버튼 터치
  2. 화면 우측 상단(또는 하단) [📲 앱 설치] 버튼 클릭
    (안 보이면 브라우저 메뉴 [⋮ → 앱 설치 / 홈 화면에 추가])
  3. 바탕화면에 전용 아이콘 앱 생성 완료!

🍎 아이폰 · 아이패드 (반드시 Safari 브라우저)

  1. Safari로 아래 앱 열기 버튼 터치
  2. 화면 하단 가운데 공유 버튼 [□↑] 터치
  3. 아래로 내려 [홈 화면에 추가] → [추가] 터치!
